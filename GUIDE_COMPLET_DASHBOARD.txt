🔌 API ENDPOINTS INTÉGRÉS:

   GET  /health                   → Status API (sidebar footer)
   POST /trends/collect           → Lance collecte (page Trends)
   GET  /trends/topK?k=20         → Top K tendances
   POST /predict                  → Prédiction virale
   POST /compare                  → Comparaison plateformes
   POST /generate/script          → Script LLM (Groq)
   POST /generate/video           → Vidéo MP4 (MoviePy)

🚀 WORKFLOW EXEMPLE:

1. Ouvrir http://localhost:3000 → Redirige vers /dashboard
2. Cliquer "Tendances Virales" dans sidebar
3. Cliquer "Lancer Collecte" → Attend 5s → Table se remplit
4. Cliquer "Prédiction ML" dans sidebar
5. Entrer: "Top 10 AI Tools 2025", TikTok, 50K followers
6. Cliquer "Analyser le Potentiel"
7. Voir: Graphiques + Métriques + Recommandations
8. Cliquer "Génération Contenu" dans sidebar
9. Entrer: "AI Tutorial", Instagram, 60s
10. Cliquer "Générer Script" → Script apparaît
11. Cliquer "Générer Vidéo" → Player vidéo apparaît
12. Télécharger MP4 + Script
